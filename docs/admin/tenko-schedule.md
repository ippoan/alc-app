# 予定管理

## 概要

「予定管理」タブでは、乗務員ごとの点呼の予定（スケジュール）を登録・編集・削除します。業務前の自動点呼は、
ここで登録した予定がある乗務員だけが受けられます。業務後の点呼は、予定が無くても乗務員が実施できます。

![予定管理タブ](../images/admin-mgr-schedule.png)

## 予定の登録

1. 「+ 新規作成」を押します
2. 1 行に 1 件の予定を入力します。「+ 行追加」で複数の予定をまとめて登録できます

    | 項目 | 内容 |
    |------|------|
    | 乗務員 | 点呼を受ける乗務員（名前・社員番号で検索できます） |
    | 種別 | 業務前 / 業務後 |
    | 予定日時 | 点呼の実施予定日時 |
    | 管理者 | その点呼に責任を持つ運行管理者の氏名（**必須**） |
    | 指示事項 | 乗務員に伝える指示事項。業務前は**必須**、業務後は任意。過去に使った指示事項から選ぶこともできます |
    | 車両番号 | 乗務する車両の番号（任意）。点呼の車両番号の段で最初から入った状態になります |

3. 「作成」を押します

指示事項は、乗務員の点呼の画面に運行管理者の氏名とともに表示され、乗務員が「確認しました」を押すまで点呼は
完了しません。

## 予定の確認・編集・削除

一覧には、乗務員・種別・予定日時・管理者・指示・車両番号・状態（未消費 / 消費済）が表示されます。
種別・状態で絞り込んで「検索」できます。

- **未消費**: まだ点呼に使われていない予定
- **消費済**: 乗務員が選んで点呼を始めた予定

「編集」で内容を変更して「保存」、「削除」→「本当に削除」で削除します。

点呼の実施状況（進行中・中断・完了・中止）と結果は、「点呼」タブの一覧と詳細で確認します（[点呼記録](tenko-record.md)）。

## 予定超過の分数

予定の時刻からこの分数を過ぎても点呼が完了していない予定は、**予定超過**として扱われます。

1. 「予定超過の分数」に 1 〜 1440 の分数を入力します（設定していない場合は 60 分）
2. 「保存」を押します。「保存しました」と表示されれば完了です

予定超過になった予定は、「点呼」タブのダッシュボードに「期限超過スケジュール」として、超過している分数とともに
表示されます。また、通知先を設定している場合は「点呼遅延」として通知されます（[通知](webhook.md)）。
点呼を始めていても、完了・中止になっていない予定（中断中・判定待ち・途中のもの）は予定超過に数えます。
