# 点呼・点呼記録

## 点呼

「点呼」タブでは、点呼の実施状況の確認と、点呼の中断・再開・中止を行います。

![点呼タブ](../images/admin-mgr-tenko.png)

### ダッシュボード

タブの上部に、次の件数が表示されます。「更新」で最新の状態に更新します。

| 表示 | 内容 |
|------|------|
| 未消費予定 | まだ点呼に使われていない予定の件数 |
| 進行中セッション | 実施中の点呼の件数 |
| 中断中 | 中断されたまま再開されていない点呼の件数 |
| 本日完了 | 今日完了した点呼の件数 |
| 本日キャンセル | 今日中止された点呼の件数 |

予定超過の予定があるときは「期限超過スケジュール」に、乗務員・種別・予定日時・管理者・超過している分数が
表示されます（予定超過の分数は [予定管理](tenko-schedule.md) で設定します）。

### 点呼の一覧

点呼ごとに、開始日時・乗務員・種別（業務前 / 業務後）・区分（点呼の方法）・ステータス・アルコール・体温・血圧・
車検・管理者が表示されます。乗務員・ステータス・種別・期間で絞り込んで「検索」できます。

| ステータス | 意味 |
|-----------|------|
| 本人確認済 〜 報告待ち | 実施中（いまどの段にいるか） |
| 中断 | 安全運転判定の不合格、または運行管理者の操作で中断された |
| 完了 | すべての段が済み、点呼の記録が保存された |
| キャンセル | アルコール検知・日常点検異常、または運行管理者の操作で中止された |

### 点呼の中断・中止

実施中の点呼は、一覧の「中断」または「キャンセル」で止められます。

- **中断**: 理由（任意）を入れて「中断」を押します。後から再開できます
- **キャンセル（中止）**: 理由と**代替措置の内容**（任意。乗務させなかった場合の代わりの措置など）を入れて「確定」を
  押します。中止した点呼は再開できません

### 中断された点呼の再開

安全運転判定の不合格などで中断された点呼は、運行管理者が中断の内容を確認したうえで再開できます。
再開は運行管理者のログインからだけ行えます。

1. 一覧で中断の点呼を押し、詳細で中断に至った内容（不合格の項目・平時の値との差・自己申告・中断の日時）を確認します
2. 一覧の「再開」を押します
3. 「再開理由」と「再開の判断を行った運行管理者の氏名」を入力します（**どちらも必須**。入力するまで「再開」は押せません）
4. 「再開」を押します

再開の理由・運行管理者の氏名・再開の日時は自動で記録されます。再開した点呼は、乗務員が点呼端末で「続きから再開」を
選び、指静脈で本人と一致したときだけ、中断した段の次の段から続けられます。体温・血圧が有効時間を過ぎている場合は
測り直しから始まります。

## 点呼記録

### 記録される内容

点呼が閉じる（完了・中止）たびに、その点呼の記録が乗務員ごとに保存されます。一覧の行を押すと詳細が表示されます。

| 区分 | 内容 |
|------|------|
| 点呼 | 乗務員・種別・区分（点呼の方法）・ステータス・責任を持つ運行管理者・開始と完了の日時・車両番号 |
| アルコール検査 | 結果（検知の有無）・測定値（mg/L）・検査日時 |
| 動画・顔写真 | アルコール測定中の動画と顔写真 |
| 医療データ | 体温・血圧・脈拍 |
| 車検証 | 管理番号・車両・車検期限・照合の方法 |
| 自己申告 | 疾病・疲労・睡眠不足の申告 |
| 安全判定 | 合格 / 不合格、不合格の項目、平時の値との差 |
| 日常点検 | 各項目の OK / NG |
| 運行報告 | 自動車・道路・運行の状況、交替運転者への通告（業務後） |
| 中断情報 | 中断の日時・理由、再開の日時・理由・判断した運行管理者 |

点呼を受けた場所は、点呼端末が所属する営業所（位置を測れる端末では、その位置）として記録されます。
点呼を受けている状況は、拠点のカメラで録画されます。録画は「拠点カメラの録画」タブで確認できます。

### 記録の保存と修正・削除

!!! warning "点呼記録は修正・削除できません"
    点呼記録は作成後の修正・削除ができません（データベースが拒否します）。記録ごとに内容全体の要約値を残し、
    書き換えがないことを確かめられるようにしています。点呼記録は 1 年以上保存されます。

### CSV エクスポート

「点呼」タブで絞り込んだ条件（期間・乗務員・種別・ステータス）のまま「CSV出力」を押すと、該当する点呼記録を
CSV でダウンロードできます。CSV には次の列が含まれます。

| 列 | 内容 |
|----|------|
| record_id | 記録の番号 |
| employee_name | 乗務員 |
| tenko_type | 種別（業務前 / 業務後） |
| tenko_method | 点呼の方法（自動点呼・遠隔点呼・対面点呼など） |
| status | ステータス |
| responsible_manager_name | 責任を持つ運行管理者 |
| started_at / completed_at | 開始・完了の日時 |
| location | 点呼を受けた場所 |
| alcohol_result / alcohol_value | アルコールの結果・測定値 |
| alcohol_has_face_photo | 顔写真の有無 |
| temperature / systolic / diastolic / pulse | 体温・最高血圧・最低血圧・脈拍 |
| temperature_diff / systolic_diff / diastolic_diff | 体温・最高血圧・最低血圧と平時の値との差 |
| instruction / instruction_confirmed_at | 指示事項・確認した日時 |
| report_vehicle_road_status | 自動車・道路・運行の状況 |
| report_driver_alternation | 交替運転者への通告 |
| report_no_report | 報告なし |
| self_declaration_illness / self_declaration_fatigue / self_declaration_sleep | 自己申告（疾病・疲労・睡眠不足） |
| safety_judgment_status / safety_judgment_failed_items | 安全運転判定・不合格の項目 |
| manager_judgment / manager_judgment_reason / manager_judgment_by_name | 運行管理者の判定・理由・判定した運行管理者（遠隔点呼・対面点呼） |
| daily_inspection_status | 日常点検の結果 |
| interrupted_at | 中断の日時 |
| resumed_at / resume_reason / resumed_by_name | 再開の日時・理由・判断した運行管理者 |
| cancel_reason / alternative_measure | 中止の理由・代替措置 |
| vehicle_number / vehicle_number_source | 車両番号・取得元（車検証 / 予定 / 入力） |
| carins_cert_no / carins_vehicle_id / carins_expires_on / carins_matched_by | 車検証の管理番号・車両・車検期限・照合の方法 |
| recorded_at | 記録した日時 |
| record_hash | 記録の要約値 |

CSV は Excel でそのまま開けます（文字コードは UTF-8、BOM 付き）。
