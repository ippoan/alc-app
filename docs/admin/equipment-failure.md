# 故障記録

## 概要

「故障記録」タブでは、点呼に使う機器・記録・通信の失敗を記録し、対応を管理します。

![故障記録タブ](../images/admin-mgr-equipment-failure.png)

故障記録には次の 2 通りがあります。

| 記録のされ方 | 内容 |
|------|------|
| 自動 | 点呼端末で機器・保存・通信の失敗が起きたとき（点呼の記録を保存できなかった、測定の記録に失敗した、写真を保存できなかった など）、発生日時・内容・機器名とともに自動で記録されます |
| 手動 | 運行管理者が「+ 故障報告」から記録します |

## 故障の記録（手動）

1. 「+ 故障報告」を押します
2. 「故障種別」を選びます（分からないときは「手動報告」）
3. 「対象機器」（任意。例: キオスク端末A）と「説明」（故障の詳細）を入力します
4. 「報告」を押します

## 故障の確認

一覧には、検出日時・種別・説明・対象機器・状態（未解決 / 解決済）が表示されます。種別・状態・期間で絞り込んで
「検索」できます。

## 対応状況の更新

1. 対応が済んだ故障の「解決記録」を押します
2. 「解決メモ」に対応の内容を入力し、「解決」を押します

解決を記録すると、変更前の内容が履歴に残ります。「履歴」を押すと、いつ変更されたかと変更前の状態・解決メモを
確認できます。

!!! warning "故障記録は削除できません"
    故障記録は削除できず、1 年以上保存されます。対応を記録するたびに、変更前の内容が修正・削除できない履歴として
    残ります。

## CSV エクスポート

絞り込んだ期間のまま「CSV出力」を押すと、故障記録を CSV でダウンロードできます。

## 製作元への連絡

故障が続く場合や、原因が分からない場合は、製作元へ連絡してください（[サポート](../support/index.md)）。
