# 運行管理者ガイド

運行管理者向けの操作マニュアルです。

---

## 初期設定

### ログイン

Google アカウントでログインします。ログイン後、ダッシュボードが表示されます。画面上部のロール切替で「運行管理者」を選択してください。

### 乗務員の登録

乗務員タブから乗務員を登録します。詳しくは本ページの「乗務員管理」を参照してください。

### デバイスの登録

デバイス管理タブから端末を登録します。詳しくは本ページの「デバイス管理」を参照してください。

---

## ダッシュボード

### 乗務員

乗務員の登録・編集・削除と、指静脈・顔の登録の承認を管理します。指静脈は、ここで承認すると点呼の本人確認に使えるようになります。

![乗務員タブ](../images/admin-mgr-employees.png)

### 免許証

乗務員の運転免許証情報を管理します。NFC カードで免許証を読み取り、有効期限を管理できます。

![免許証タブ](../images/admin-mgr-license.png)

### 点呼

点呼の実施状況の確認、点呼の中断・再開・中止、点呼記録の詳細と CSV 出力を行います。一覧の行をクリックした詳細に、アルコール測定時の動画・顔写真も表示されます。詳しくは [点呼・点呼記録](tenko-record.md) を参照してください。

![点呼タブ](../images/admin-mgr-tenko.png)

### 遠隔点呼

遠隔点呼モニターです。接続待ちデバイスを選び、指静脈で本人確認をしてからビデオ通話を始め、点呼を判定します。ログインせずに受ける場合は、役割タブの「点呼受付」を使います。詳しくは [遠隔点呼の実施](remote-tenko.md) を参照してください。

![遠隔点呼タブ](../images/admin-mgr-remote-tenko.png)

### 画面共有

端末の画面をリアルタイムで共有・確認できます。

![画面共有タブ](../images/admin-mgr-screen-share.png)

### 予定管理

点呼の予定（責任を持つ運行管理者・指示事項・車両番号）の登録・編集・削除と、予定超過の分数の設定を行います。詳しくは [予定管理](tenko-schedule.md) を参照してください。

![予定管理タブ](../images/admin-mgr-schedule.png)

### 健康基準

乗務員ごとの体温・血圧の平時の値と許容の幅、測定値の有効時間を設定します。安全運転判定に使われます。詳しくは [健康基準](health-baseline.md) を参照してください。

![健康基準タブ](../images/admin-mgr-health-baseline.png)

### 故障記録

機器・記録・通信の失敗の記録（自動・手動）と対応の記録を管理します。詳しくは [故障記録](equipment-failure.md) を参照してください。

![故障記録タブ](../images/admin-mgr-equipment-failure.png)

### 通知

点呼の異常（アルコール検知・日常点検 NG・中断・予定超過）をメールと Webhook で知らせます。詳しくは [通知（メール・Webhook）](webhook.md) を参照してください。

### タイムカード

NFC カードと乗務員の紐付け、打刻履歴の確認を行います。

![タイムカードタブ](../images/admin-mgr-timecard.png)

### デバイス管理

端末の登録・承認・無効化を管理します。

![デバイス管理タブ](../images/admin-mgr-devices.png)

## 乗務員管理

### 乗務員一覧

![乗務員一覧](../images/admin-employees-list.png)

| 列 | 内容 |
|----|------|
| 社員番号 | 乗務員の社員番号 |
| 名前 | 乗務員名 |
| ロール | 運行者 / 運行管理者 / システム管理者 |
| NFC | NFC カードの紐づけ状態 |
| 顔登録 | 顔認証の登録・承認状態 |
| 中間点呼 | 中間点呼の電話番号登録状態 |
| 登録日 | 登録日時 |
| 操作 | 顔登録・編集・削除ボタン |

### 乗務員の登録

「+新規登録」ボタンをタップすると登録フォームが表示されます。

![乗務員登録フォーム](../images/admin-employee-register.png)

1. 社員番号・名前を入力します
2. ロール（運行者 / 運行管理者 / システム管理者）を選択します
3. 「登録」をタップします

### 乗務員の編集

一覧の「編集」ボタンから名前・ロールを変更できます。

### 乗務員の削除

一覧の「削除」ボタンをタップすると確認が表示されます。

![削除確認](../images/admin-employee-delete.png)

「本当に削除」をタップすると乗務員が削除されます。

### 顔認証の登録状況

![承認待ち状態](../images/admin-employees-pending.png)

| ステータス | 内容 |
|-----------|------|
| 未登録 | 乗務員がまだ顔を登録していない |
| 承認待ち | 顔が登録され、管理者の承認を待っている |
| 承認済 | 管理者が顔登録を承認した |

承認待ちの乗務員には「承認」「却下」ボタンが表示されます。「承認」をタップすると、その乗務員の顔認証が有効になります。

## デバイス管理

### 登録フロー

3種類の登録フローを提供します。

| フロー | 流れ | 承認 | 有効期限 |
|--------|------|------|---------|
| QR一時コード（推奨） | 管理者がQR生成 → 端末でスキャン → 即登録 | 不要 | 10分 |
| QR永久コード | 管理者がQR生成(PDF印刷可) → 端末でスキャン → 管理者が承認 | 必要 | なし |
| URL共有 | 管理者がURL生成 → LINE等で共有 → 端末で登録 | 不要 | 24時間 |

### デバイス一覧

登録済みデバイスの一覧が表示されます。ステータス（有効 / 無効）、デバイス名、電話番号、登録日を確認できます。

### 承認・却下

QR永久フローで登録されたデバイスは「承認待ち」状態になります。「承認」または「却下」をクリックして処理します。

### 着信設定

デバイスごとに遠隔点呼の着信 ON/OFF とスケジュールを設定できます。

### デバイスの無効化・削除

デバイスの「無効化」で一時的に利用を停止、「削除」で完全に削除できます。
