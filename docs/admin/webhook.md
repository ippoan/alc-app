# 通知（メール・Webhook）

## 概要

点呼で異常があったときに、運行管理者や事業者のシステムへ知らせる方法は 2 つあります。

| 方法 | 送り先 | 設定する場所 |
|------|--------|-------------|
| メール | 通知の管理画面で登録したグループのメンバー（1 人 1 通） | 通知の管理画面（グループとメンバー） |
| Webhook | 事業者のシステムの URL | システム管理者の「Webhook」タブ |

## メールの通知

通知の管理画面で、決まった名前のグループを作り、メールを受け取る人をメンバーに加えます。グループのメンバー
（メールアドレスが登録され、有効になっている人）へ、1 人 1 通ずつメールが送られます。

| グループ名 | 送られるとき | 内容 |
|-----------|-------------|------|
| アルコール検知 | 測定でアルコールが検知されたとき | 件名「アルコール検知: 乗務員名」。乗務員名・アルコール値・測定日時が書かれ、測定時の顔写真が添付されます |
| 点呼の異常 | 日常点検に NG があったとき、点呼が中断されたとき、予定超過（点呼遅延）になったとき | 乗務員名と異常の内容 |

### グループの作り方

1. 通知の管理画面を開きます
2. グループを新しく作り、名前を上の表のとおり（「アルコール検知」「点呼の異常」）にします。名前が違うと送られません
3. メールを受け取る人（運行管理者など）をメンバーに加え、メールアドレスを登録します

グループが無い、またはメンバーがいない場合は、メールは送られません。

## Webhook の通知

Webhook は、点呼の出来事を事業者のシステムへ自動で送る仕組みです。システム管理者が「Webhook」タブで設定します。

### Webhook の追加

1. 「+ 新規作成」を押します
2. 「イベント種別」を選びます
3. 送り先の URL（`https://...`）を入力します
4. 「有効」をオンにして「作成」を押します

### イベント種別

点呼の異常を知らせるイベントは次の 4 つです。

| イベント種別 | 送られるとき |
|-------------|-------------|
| アルコール検出 | 点呼でアルコールが検知され、点呼が「アルコール検知」として中止されたとき |
| 点呼遅延 | 予定超過の分数を過ぎても点呼が完了していないとき（[予定管理](tenko-schedule.md)） |
| 点呼中断 | 安全運転判定の不合格、または運行管理者の操作で点呼が中断されたとき |
| 日常点検NG | 日常点検に NG があり、点呼が「日常点検異常」として中止されたとき |

### 配信履歴

一覧の「配信履歴」を押すと、送った日時・結果（成功 / 失敗）・ステータス・試行回数・応答が表示されます。
送り先が応答しなかった場合は、自動で再送されます。

### Webhook の削除

一覧の「削除」→「本当に削除」で削除します。一時的に止めたいときは、新しく作るときに「有効」をオフにします。
