# ALC アプリ 操作マニュアル

業務用アルコール検知・点呼管理システムの操作マニュアルです。

## このマニュアルについて

本マニュアルでは、ALC アプリの各機能の操作方法と、サポート体制を説明します。

## 対象読者

| セクション | 対象 | 内容 |
|-----------|------|------|
| [運行者向け](operator/index.md) | 乗務員 | 自動点呼の受け方（指静脈の本人確認・体温血圧・自己申告・日常点検・アルコール測定・指示事項・運行報告）、タイムカード |
| [運行管理者](admin/index.md) | 運行管理者 | 予定管理、健康基準、点呼と点呼記録、故障記録、通知、乗務員・デバイスの管理 |
| [システム管理者](admin/sysadmin.md) | システム管理者 | Webhook などのシステム設定 |
| [サポート](support/index.md) | 事業者 | 修理体制、不具合の受付と改善、品質管理体制 |

## システム構成

| 構成 | 内容 |
|------|------|
| 点呼端末 | 点呼の画面を表示する PC・タブレット。Chrome または Edge でアプリを開きます |
| 指静脈の読取装置 | 本人確認に使います |
| アルコール検知器 | タニタ FC-1200 |
| 体温計・血圧の測定台 | 業務前の点呼の体温・血圧を測ります |
| 運行管理者の PC | 予定・健康基準の設定、点呼の確認、遠隔点呼を行います |

点呼の記録はサーバーに保存され、運行管理者の画面から確認できます。

## 動作環境

- ブラウザ: Google Chrome または Microsoft Edge（最新版）
- 点呼端末と運行管理者の PC は、インターネットにつながっている必要があります
