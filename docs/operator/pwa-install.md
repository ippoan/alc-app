# アプリのインストール

## 概要

ALC アプリは、開いたときの URL によって **2 つの別々のアプリ**としてインストールできます。
点呼をする端末には「点呼キオスク」を、運行管理者の PC には「運行管理者」を入れてください。
同じ PC に両方を入れることもできます。

| 入れるアプリ | 開く URL | アイコン | 主に入れる端末 |
|---|---|---|---|
| 点呼キオスク | `/?role=driver` | 青 | 点呼をする Android タブレット・キオスク PC |
| 運行管理者 | `/?role=manager` | オレンジ（人型） | 運行管理者の Windows PC |

アイコンの色が違うので、タスクバーに 2 つ並んでも見分けられます。

## インストール手順（Chrome / Edge）

1. インストールしたい方の URL をブラウザで開きます
     - 点呼キオスク: アプリの URL のうしろに `?role=driver` を付けます
     - 運行管理者: アプリの URL のうしろに `?role=manager` を付けます
2. アドレスバー右端のインストールアイコン、または右上のメニューから
   **「アプリをインストール」**（Edge では「アプリとしてインストール」）を選びます
3. 表示されるアプリ名が、入れたい方（「点呼キオスク」または「運行管理者」）になっていることを
   確認して「インストール」を押します

インストールしたアプリを起動すると、必ずそのロールの画面で開きます。アプリの中でロールタブを
切り替えることは今までどおりできます。

!!! tip "運行管理者の PWA と警告デバイス"
    運行管理者のアプリを Windows に入れておくと、警告デバイスのバーはそのアプリの中に出ます。
    ブラウザのタブを探さずに済むので、据置の運行管理者 PC ではこちらを推奨します。
    警告デバイスの接続手順は「警告デバイス」を参照してください。

## うまくいかないとき

**2 つ目をインストールしようとすると「インストール済み」と言われる**

ブラウザが 1 つ目のアプリと同じものだと判断しています。URL に `?role=` が入っているか
確認してください。それでも直らない場合は、Chrome のアドレスバーに
`chrome://web-app-internals` と入力し、インストール済みアプリの一覧を開きます。
`/?role=driver` と `/?role=manager` の 2 件が別々に並んでいれば正しい状態です。
片方しか無いのに「インストール済み」と出る場合は、ブラウザを再起動してから開き直してください。

**インストールの選択肢が出てこない**

- `http://` ではなく `https://` で開いているか確認してください
- ページを再読み込みしてから、もう一度メニューを開いてください
