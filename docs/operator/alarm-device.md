# 警告デバイス

## 概要

警告デバイス（Atom VoiceS3R）は、点呼キオスクの PC に USB でつなぐ据置のブザーです。

キオスクの画面は 3 秒ごとに「正常」または「異常」をデバイスへ送っています。デバイスは
**この合図が 10 秒以上とだえたら、自分の判断で鳴ります**。画面から「鳴れ」と命令している
わけではないので、タブを閉じた・ブラウザが落ちた・PC がフリーズした、のいずれでも同じように
鳴ります。

## 接続手順

初回だけ、ブラウザにポートの使用を許可させる操作が必要です。

1. 警告デバイスをキオスク PC に USB ケーブルでつなぎます
2. メンテナンス画面（設定画面）を開きます
3. 「警告デバイス（Atom VoiceS3R）」の欄にある **「警告デバイスを接続」** を押します
4. ブラウザのポート選択ダイアログが出ます。一覧から警告デバイスを選んで「接続」を押します
5. 欄の表示が「接続」に変わり、点呼画面にも「警告デバイス: 接続」と出れば完了です

一度許可すれば、次回からは点呼画面を開くだけで自動的につながります。

!!! info "どれを選べばよいか分からないとき"
    警告デバイスと BLE ゲートウェイは USB 上の見た目が同じなので、ポート選択ダイアログでは
    区別がつきません。間違えて選んでも壊れません。アプリが起動後に自動で見分けて、
    正しい組み合わせにつなぎ直します。

## 鳴ったときの意味

点呼画面の「警告デバイス」の行に理由が表示されます。

| 表示 | 意味 | 対処 |
|------|------|------|
| 鳴動中（無音） | キオスクの画面から合図が届かなくなりました。タブを閉じた、ブラウザが落ちた、PC がフリーズした、USB が抜けた | 点呼画面を開き直してください。画面が固まっている場合はブラウザを再起動します |
| 鳴動中（FC-1200 未接続） | 画面は動いているが、アルコールチェッカー（FC-1200）がつながっていません | FC-1200 の USB を挿し直し、メンテナンス画面で接続状態を確認してください |
| 停止済み（人が止めた・…） | 本体のボタンで音だけ止めた状態です | **異常は続いています。** 上の対処を行ってください |
| 未接続 | 警告デバイスが見つかっていません | USB を挿し直し、上の「接続手順」をやり直してください |

## 本体のボタン

本体のボタンを押すと**音は止まりますが、異常そのものは解消しません**。画面の表示は
「停止済み（人が止めた・…）」に変わり、原因が残っていることを示し続けます。原因を直すまで
放置しないでください。

!!! warning "PC が落ちると鳴りません"
    警告デバイスの電源は USB からとっています。PC の電源が切れる・コンセントが抜けるといった
    場合は、デバイス自身も止まるため鳴りません。停電や PC の電源断は、この仕組みでは
    検知できません。
