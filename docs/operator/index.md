# 運行者ガイド

乗務員向けの操作マニュアルです。

---

## はじめに

### 概要

ALC アプリは、業務用アルコール検知・点呼管理システムです。運転免許証（NFC）または社員番号で乗務員を特定し、
指静脈で本人であることを確かめてから、体温・血圧、自己申告、日常点検、アルコール測定、指示事項の確認までを
一連の流れで実施します。

### 使う機器

| 機器 | 役割 |
|------|------|
| 点呼端末（PC・タブレット） | 点呼の画面を表示します |
| 指静脈の読取装置（Vein Station） | 本人確認に使います。点呼端末に USB でつなぎます |
| アルコール検知器（タニタ FC-1200） | 呼気中のアルコール濃度を測ります |
| 体温計 | 業務前の点呼で体温を測ります |
| 血圧の測定台 | 業務前の点呼の前に血圧を測っておく台です（下の「バイタル測定」を参照） |
| 電子車検証の読取装置 | 車両番号を電子車検証から読み取ります（無い拠点では車両番号を選びます） |

### 画面の見かた

アプリのメイン画面は、上部のタブで機能を切り替えます。

| タブ | 機能 |
|------|------|
| 通常点呼 | NFC カードで乗務員を識別し、アルコール測定を実施 |
| 自動点呼 | 点呼の予定に沿って、業務前・業務後の点呼を運行管理者の立ち会いなしで実施（下の「自動点呼」を参照） |
| 遠隔点呼 | 運行管理者とビデオ通話しながら点呼を実施 |
| タイムカード | NFC カードで出退勤の打刻 |

点呼の画面の上部には段（ステップ）の一覧が表示され、いまの段が青、済んだ段が緑で示されます。

## アプリのインストール

### 概要

ALC アプリは、開いたときの URL によって **2 つの別々のアプリ**としてインストールできます。
点呼をする端末には「点呼キオスク」を、運行管理者の PC には「運行管理者」を入れてください。
同じ PC に両方を入れることもできます。

| 入れるアプリ | 開く URL | アイコン | 主に入れる端末 |
|---|---|---|---|
| 点呼キオスク | `/?role=driver` | 青 | 点呼をする Android タブレット・キオスク PC |
| 運行管理者 | `/?role=manager` | オレンジ（人型） | 運行管理者の Windows PC |

アイコンの色が違うので、タスクバーに 2 つ並んでも見分けられます。

### インストール手順（Chrome / Edge）

1. インストールしたい方の URL をブラウザで開きます
     - 点呼キオスク: アプリの URL のうしろに `?role=driver` を付けます
     - 運行管理者: アプリの URL のうしろに `?role=manager` を付けます
2. アドレスバー右端のインストールアイコン、または右上のメニューから
   **「アプリをインストール」**（Edge では「アプリとしてインストール」）を選びます
3. 表示されるアプリ名が、入れたい方（「点呼キオスク」または「運行管理者」）になっていることを
   確認して「インストール」を押します

インストールしたアプリを起動すると、必ずそのロールの画面で開きます。アプリの中でロールタブを
切り替えることは今までどおりできます。

!!! tip "運行管理者の PWA と警告デバイス"
    運行管理者のアプリを Windows に入れておくと、警告デバイスのバーはそのアプリの中に出ます。
    ブラウザのタブを探さずに済むので、据置の運行管理者 PC ではこちらを推奨します。
    警告デバイスの接続手順は「警告デバイス」を参照してください。

### うまくいかないとき

**2 つ目をインストールしようとすると「インストール済み」と言われる**

ブラウザが 1 つ目のアプリと同じものだと判断しています。URL に `?role=` が入っているか
確認してください。それでも直らない場合は、Chrome のアドレスバーに
`chrome://web-app-internals` と入力し、インストール済みアプリの一覧を開きます。
`/?role=driver` と `/?role=manager` の 2 件が別々に並んでいれば正しい状態です。
片方しか無いのに「インストール済み」と出る場合は、ブラウザを再起動してから開き直してください。

**インストールの選択肢が出てこない**

- `http://` ではなく `https://` で開いているか確認してください
- ページを再読み込みしてから、もう一度メニューを開いてください

## 本人確認（指静脈）

### 概要

点呼の本人確認は指静脈で行います。運転免許証（NFC）または社員番号で特定した乗務員と、読取装置に置いた指の
静脈を 1 対 1 で照合し、一致したときだけ点呼を始めます。指静脈の読取装置（Vein Station）が点呼端末に
つながっていないときは、点呼は先へ進みません。

### 指静脈の登録

指静脈は、事前に血圧の測定台の画面から登録します。

1. 測定台の画面で運転免許証をかざすか、社員番号を入力します
2. 「指静脈を登録する」を押し、読取装置の案内に従って指を置きます
3. 「指静脈を登録しました」と表示されたら完了です

登録した指静脈は、運行管理者が承認すると照合に使えるようになります。すでに登録済みの指と一致した場合は、
その端末の分は自動で承認され、すぐに使えます。

### 本人確認のしかた

1. 点呼の「本人確認」の段で「指静脈で本人確認」を押します
2. 「指を置いてください…」と表示されたら、読取装置に指を置きます
3. 「もう一度置いてください…」と表示されたら、指を置き直します
4. 照合が一致すると、自動で次の段へ進みます

### 本人確認ができない場合

- 「Vein Station (指静脈読み取り端末) が接続されていません」と表示された場合は、読取装置の USB ケーブルが
  点呼端末につながっているか確認してください
- 一致しない場合は、登録したときと同じ指を、読取装置の奥まで平らに置き直してください
- 何度置いても一致しない場合は、運行管理者に連絡してください

## 自動点呼

### 概要

自動点呼は、運行管理者があらかじめ登録した点呼の予定に沿って、業務前・業務後の点呼を点呼端末だけで実施する
機能です。前の段が済まないと次の段へは進めません。すべての段が済むと点呼の記録が保存され、「点呼完了」が
表示されます。

### 点呼の流れ

**業務前の自動点呼**

| 順 | 段 | 内容 |
|----|----|------|
| 1 | 乗務員の特定 | 運転免許証（NFC）をかざすか、「手動でIDを入力する」から社員番号を入力します |
| 2 | 予定の選択 | 自分の未実施の点呼予定（種別・予定日時・運行管理者・指示）から、実施するものを選びます |
| 3 | 本人確認 | 指静脈で本人であることを確かめます（上の「本人確認（指静脈）」を参照） |
| 4 | 車両番号 | 電子車検証を読取装置にかざすか、車両番号を選びます |
| 5 | 体温・血圧 | 体温を測ります。血圧は測定台で測った値が自動で使われます（下の「バイタル測定」） |
| 6 | 自己申告 | 疾病・疲労・睡眠不足の 3 項目に答えます（下の「自己申告」）。送信と同時に安全運転判定が行われます |
| 7 | 日常点検 | 車両の点検項目に OK / NG で答えます（下の「日常点検」） |
| 8 | 携行品 | 運行に必要な携行品を確認します（携行品が登録されていない事業所では表示されません） |
| 9 | アルコール | アルコール検知器で測定します（下の「アルコール測定」） |
| 10 | 指示事項確認 | 運行管理者からの指示事項を確認します（下の「指示事項確認」） |
| 11 | 完了 | 点呼の結果が表示されます（下の「完了」） |

業務前の自動点呼は、点呼の予定がある場合だけ実施できます。予定が表示されない場合は運行管理者に連絡してください。

**業務後の自動点呼**

| 順 | 段 | 内容 |
|----|----|------|
| 1 | 乗務員の特定 | 運転免許証（NFC）または社員番号 |
| 2 | 予定の選択 | 業務後の予定を選びます。予定が無い場合は「予定なしで業務後として進む」を押します |
| 3 | 本人確認 | 指静脈 |
| 4 | 車両番号 | 電子車検証または車両番号の選択 |
| 5 | アルコール | アルコール検知器で測定します |
| 6 | 運行報告 | 自動車・道路・運行の状況と、交替運転者への通告を報告します（下の「運行報告」） |
| 7 | 指示事項確認 | 予定に指示事項がある場合に表示されます |
| 8 | 完了 | 点呼の結果が表示されます |

### 車両番号

電子車検証の読取装置がある点呼端末では、電子車検証をかざすと車両番号が登録されます。読み取れない場合や
一致する車両が見つからない場合は、ナンバーの右側の数字（例: 7601）を打って候補から選ぶか、車両番号を入力して
「登録して次へ」を押します。予定に車両番号が登録されている場合は、その番号が最初から入っています。

業務前の点呼は、車両番号が登録されるまで完了できません。

### バイタル測定

業務前の自動点呼では、体温と血圧を記録します。**手入力や測定の省略はできません。**

**体温**

「体温・血圧」の段で、点呼端末につないだ体温計で体温を測ります。測定値は自動で画面に表示されます。
「次へ」を押すと記録されます。

**血圧（測定台）**

血圧は点呼端末では測りません。点呼の前に、**血圧の測定台**で測っておきます。

1. 測定台の画面で運転免許証をかざすか、社員番号を入力します
2. 「指を置いて照合」を押し、指静脈で本人確認をします（本人と一致したときだけ測定できます）
3. 血圧計で血圧を測ります。「測定完了」と表示されたら記録されています

点呼の「体温・血圧」の段に進むと、測定台で測った値のうち、**有効時間内の最新の値**が自動でその点呼に使われます。
有効時間は運行管理者が乗務員ごとに設定します（設定が無い場合は 30 分）。

**有効時間を過ぎた場合・測定台の血圧が無い場合**

- 体温・血圧の測定から有効時間を過ぎていると「体温・血圧の測定から有効時間を過ぎました。もう一度測定してください」
  と表示されます。測り直してから進めてください
- 有効時間内の測定台の血圧が無い場合は、その点呼は遠隔点呼に切り替わり、運行管理者がビデオ通話で確認します
- 血圧計が故障している・つながっていない場合は、「遠隔点呼に切り替える」を押して理由を選ぶと、
  運行管理者がビデオ通話で確認する遠隔点呼に切り替わります

!!! info "血圧の記録が 10 日分に満たない場合"
    業務前の自動点呼は、血圧の記録が 10 日分そろっている乗務員だけが受けられます。10 日分に満たない場合は、
    点呼の開始時に「血圧の記録が 10 日分そろっていないため、対面点呼になります」と表示されます。
    点呼の段はそのまま進め、最後に運行管理者に会って確認を受けてください。

### 安全運転判定

自己申告を送信すると同時に、次の内容から安全な運転をすることができないおそれがあるかが自動で判定されます。

- 体温・最高血圧・最低血圧と、運行管理者が乗務員ごとに設定した平時の値との差が、許容の幅に収まっているか
- 自己申告で「はい」と答えた項目があるか

判定の基準（平時の値と許容の幅）は運行管理者が乗務員ごとに設定します。
判定が合格なら日常点検の段へ進みます。不合格の場合は、その場で点呼が中断されます
（下の「自己申告 > 申告内容と安全運転判定」と「点呼が中断された場合」を参照）。

### 指示事項確認

運行管理者が点呼の予定に登録した指示事項が、運行管理者の氏名とともに表示されます。業務前の点呼では
アルコール測定の後に表示されます。内容を読んで「確認しました」を押してください。「確認しました」を押すまで
点呼は完了しません。確認した時刻も記録されます。

### 運行報告

業務後の点呼では、次の 2 項目を報告します。

| 項目 | 内容 |
|------|------|
| 1. 自動車・道路・運行の状況 | 車両の異常、道路状況、運行の状況など |
| 2. 交替運転者への通告 | 交替の有無、通告内容など |

1. 項目ごとに「報告あり」か「報告なし」を選びます
2. 「報告あり」の場合は、「テキスト入力」で文字を入力するか、「音声録音」で「録音開始」→「録音終了」で
   声を録音します
3. 2 項目とも答えたら「送信」を押します

両方の項目に答えるまで送信できません。報告の内容は点呼の記録に残り、運行管理者が確認します。

### 完了

すべての段が済むと「点呼完了」が表示されます。画面には次の内容が表示されます。

- 点呼の種別、運行管理者の氏名
- 開始と完了の時刻
- アルコールの測定値、体温、血圧

「次の点呼へ」を押すか、表示された秒数が過ぎると最初の画面に戻ります。

次の場合は「点呼完了」にはなりません。

- 指示事項の確認・運行報告（業務後）・車両番号（業務前）が済んでいない
- 点呼の記録を保存できなかった（通信の不調など。この場合は機器の故障として記録されます。もう一度操作するか、
  運行管理者に連絡してください）

!!! note "遠隔点呼・対面点呼に切り替わった点呼"
    遠隔点呼や対面点呼に切り替わった点呼では、最後に「入力完了」と表示されます。点呼の判定は運行管理者が行うので、
    そのまま終わって大丈夫です。

### 点呼が中断された場合

**安全運転判定で中断された場合**

画面に「点呼中断」と、不合格になった項目（疾病・疲労・睡眠不足・最高血圧・最低血圧・体温）が表示されます。
「運行管理者に連絡してください」の案内に従い、運行管理者に連絡してください。

運行管理者が内容を確認して点呼を再開すると、続きから点呼を受けられます。

1. 自動点呼の画面で、運転免許証をかざすか社員番号を入力します
2. 予定の選択の画面に「途中で止まっている点呼」が表示されます。「続きから再開」を押します
3. 指静脈で本人確認をします。本人と一致したときだけ再開されます
4. 中断した段の次の段から点呼が続きます

体温・血圧の測定から有効時間を過ぎている場合は、体温・血圧の測り直しから始まります。

**途中で画面を閉じた・「最初からやり直す」を押した場合**

アルコールをまだ測っていない点呼は、同じ手順（「続きから再開」→ 指静脈で本人確認）で続きから再開できます。
アルコールを測った後の点呼は再開できません。新しく点呼をやり直してください。

!!! warning "アルコール検知・日常点検 NG で中止された点呼"
    アルコールが検知された点呼と、日常点検に NG があった点呼は「中止」となり、再開できません。

### よくある質問

**Q: 予定が表示されない場合は？**
A: 運行管理者が点呼の予定を登録していない可能性があります。運行管理者に確認してください。
業務後の点呼は、予定が無くても「予定なしで業務後として進む」から実施できます。

**Q: 途中でやり直したい場合は？**
A: 「最初からやり直す」を押すと最初の画面に戻ります。アルコールを測る前であれば、上の手順で続きから再開できます。

## アルコール測定

### 概要

アルコール検知器（タニタ FC-1200）を使って呼気中のアルコール濃度を測定します。アルコール測定の段は、
指静脈で本人確認をして始めた点呼の中でしか開きません。測定値は本人確認済みのその点呼にだけ記録されます。

### 測定手順

1. 点呼の「アルコール」の段に進むと、アルコール検知器との接続を待ちます
2. カメラが起動し、小さなプレビューが表示されます
3. 「息を吹きかけてください」と表示されると、自動で録画が始まります（赤い「録画中」が表示されます）
4. アルコール検知器の吹き込み口に向かって約 5 秒間息を吹きかけます
5. 測定が終わると録画が止まり、結果が自動で点呼に記録されます

![アルコール測定画面](../images/operator-alc-measurement.png)

### 測定結果の見かた

測定の結果（検知の有無と濃度 mg/L）と、吹き込み中の動画は自動で記録・保存され、運行管理者が点呼の詳細で
確認できます。

| 結果 | その後 |
|------|--------|
| 検知なし | 次の段へ進みます（業務前は指示事項確認、業務後は運行報告） |
| 検知あり | その場で点呼が「アルコール検知」として中止されます。画面の案内に従い、運行管理者に連絡してください。運行管理者には顔写真付きのメールで知らされます |
| 測定できなかった | 「測定結果を点呼に使えませんでした。もう一度測ってください」と表示されます。もう一度測ってください |

点呼完了の画面には、アルコールの測定値が表示されます。また、吹き込み中の動画の送信状態が表示されます。

| 表示 | 意味 |
|------|------|
| 録画アップロード中... | 動画を送信中です |
| 録画アップロード完了 | 動画が保存されました |
| 録画はローカルに保存済み (後でアップロード) | 通信できないため端末に保存しました。通信が戻ると自動で送ります |
| 録画アップロード失敗 (次回起動時にリトライ) | 送信に失敗しました。次にアプリを起動したときに自動で送り直します |

### 測定に失敗する場合

- 「FC-1200 が見つかりません」と表示された場合は、アルコール検知器が USB でつながっているか確認し、
  「USB 再スキャン」を押してください
- 息を吹きかける時間が短すぎると測定できません（約 5 秒間）
- 測定直後に再測定する場合は、検知器の準備が整うのを待ってください

### よくある質問

**Q: 飲酒していないのに検知された場合は？**
A: 口の中のアルコール成分（マウスウォッシュ等）で反応することがあります。点呼は中止されるので、運行管理者に
連絡し、その指示に従ってください。

## 自己申告

### 概要

自己申告は、業務前の点呼で乗務員が自身の健康状態を申告する段です。申告の内容と日時は点呼の記録に保存され、
運行管理者が点呼の詳細で確認できます。

### 申告項目

![自己申告画面](../images/operator-self-declaration.png)

次の 3 項目について「はい」または「いいえ」で答えます。

| 項目 | 質問 |
|------|------|
| 疾病 | 体調不良や疾病の自覚症状がありますか？ |
| 疲労 | 過度な疲労を感じていますか？ |
| 睡眠不足 | 睡眠不足の自覚がありますか？ |

### 申告手順

1. 各項目について「はい」または「いいえ」を選びます
2. すべての項目に答えたら「送信」を押します

### 申告内容と安全運転判定

送信と同時に安全運転判定が行われます（上の「自動点呼 > 安全運転判定」）。
次のどれかに当たると判定は不合格となり、その場で点呼が中断されます。

- 自己申告で「はい」と答えた項目がある
- 体温・最高血圧・最低血圧と平時の値との差が、許容の幅を超えている

中断されると、画面に「点呼中断」「安全運転判定: 不合格」と不合格の項目が表示され、「運行管理者に連絡してください」
と案内されます。中断は運行管理者にも通知されます。運行管理者が内容を確認して再開した場合だけ、続きから点呼を
受けられます（上の「点呼が中断された場合」）。

## 日常点検

### 概要

日常点検は、業務前の点呼で車両の安全状態を確認する段です。各項目について OK / NG を記録します。結果は点検の時刻と
ともに点呼の記録に保存されます。

### 点検項目

![日常点検画面](../images/operator-daily-inspection.png)

| 項目 | 確認内容 |
|------|----------|
| ブレーキ | ブレーキの効き具合 |
| タイヤ | タイヤの空気圧・摩耗・損傷 |
| 灯火類 | ヘッドライト・ウインカー・ブレーキランプ等 |
| ハンドル | ハンドルの操作感・遊び |
| ワイパー | ワイパーの動作・ゴムの状態 |
| ミラー | バックミラー・サイドミラーの状態 |
| 警音器 | クラクションの動作 |
| シートベルト | シートベルトの状態 |

### 点検の実施手順

1. 各項目について「OK」または「NG」を押します
2. すべての項目に答えたら「送信」を押します（全項目に答えるまで送信できません）

### NG項目がある場合

NG が 1 項目でもあると「NG 項目があります。送信すると点呼はキャンセルされます。」と表示されます。
送信すると、点呼は「日常点検異常」として中止されて記録され、運行管理者に通知されます。画面の案内に従って
運行管理者に連絡してください。車両の整備・修理を行い、問題が解消されてから、新しく点呼を受け直してください。

## 遠隔点呼

### 概要

遠隔点呼は、点呼の段を点呼端末で進めたあと、運行管理者とビデオ通話をして判定を受ける点呼です。最後の確定
（業務前は指示事項確認、業務後は運行報告）を終えると、点呼端末が運行管理者を呼びます。運行管理者が通話の中で
確認して判定すると、点呼が完了します。

### 遠隔点呼の開始

1. 「遠隔点呼」タブを押します
2. 画面上部の「業務前」「業務後」から、点呼の種別を選びます
3. 運転免許証（NFC）をかざすか、「手動でIDを入力する」から社員番号を入力します
4. 指静脈で本人確認をします（上の「本人確認（指静脈）」を参照）

遠隔点呼には予定の選択と車両番号の段はありません（運行管理者が通話の中で確かめます）。

### 着信と応答

点呼端末で応答する操作はありません。最後の確定を終えると「入力完了」の画面になり、「運行管理者を呼んでいます。
通話がつながると、運行管理者が判定して点呼が終わります」と表示されます。運行管理者が応答すると、画面にビデオ通話の
ウィンドウが表示され、運行管理者の映像と声が届きます。

運行管理者が通話に出ていない間は、「入力完了」の画面も 30 秒で最初の画面に戻ります（「あと ○ 秒で次の点呼へ移ります」）。

自動点呼の途中で遠隔点呼に切り替わった場合は、「体温・血圧」の段で運行管理者を呼びます（「自動点呼 > バイタル測定」を参照）。

### ビデオ通話中の操作

ビデオ通話のウィンドウには、運行管理者の映像と自分のカメラの映像が表示されます。運行管理者の指示に従ってください。
通話を終える操作は運行管理者が行います。

### 点呼の流れ

| 種別 | 段 |
|------|----|
| 業務前 | 乗務員の特定 → 本人確認 → 体温・血圧 → 自己申告 → 日常点検 → 携行品 → アルコール → 指示事項確認 → 運行管理者との通話 → 完了 |
| 業務後 | 乗務員の特定 → 本人確認 → アルコール → 指示事項確認 → 運行報告 → 運行管理者との通話 → 完了 |

各段の操作は自動点呼と同じです（「自動点呼」「アルコール測定」「自己申告」「日常点検」を参照）。体温は体温計で測り、
血圧は測定台で測った値が使われます。

**完了**

運行管理者が判定すると「点呼完了」と運行管理者の判定（OK / NG）が表示され、30 秒で最初の画面に戻ります。
「次の点呼へ」を押すと、待たずに戻ります。

運行管理者が出ない場合は、「運行管理者が出ないので点呼をやめる」を押すと点呼をやめて最初の画面に戻ります。
やめた点呼は中止として記録されるので、運行管理者に連絡してください。

### 通信が切れた場合

ネットワーク接続が切れた場合は、ビデオ通話の下に「再接続」と「終了」が表示されます。「再接続」を押して
つなぎ直してください。つながらない場合は「終了」を押し、運行管理者に連絡してください。

### よくある質問

**Q: ビデオ通話の映像が映らない場合は？**
A: ブラウザでカメラの使用が許可されているか確認してください。

**Q: 音声が聞こえない場合は？**
A: 端末の音量と、ブラウザでマイクの使用が許可されているかを確認してください。

**Q: 運行管理者が通話に出ない場合は？**
A: 「運行管理者が出ないので点呼をやめる」を押し、運行管理者に連絡してください。

## タイムカード打刻

### 概要

NFC カードを使って出退勤の打刻を行います。打刻の手段は 2 つあります。

| 打刻の手段 | 用途 |
|------|------|
| NFC タイムカード端末 | 営業所に常設する専用機。カードをかざすだけで打刻します |
| アプリの「タイムカード」タブ | タブレットしかない拠点、および専用機が使えないときのフォールバック |

どちらで打刻しても、記録される内容と確認のしかたは同じです。

### タップしても音は鳴りません

!!! warning "「鳴らない ＝ 故障」ではありません"
    NFC タイムカード端末には**打刻音がありません**。カードをかざしたときの端末の反応は
    **本体の LED の色だけ**です。音が鳴らないことを理由に、同じカードを何度もかざしたり、
    端末を故障として交換したりしないでください。

端末の LED は次の 3 色です。

| LED の色 | 意味 |
|------|------|
| 暗い青（常時点灯） | 待機中。電源が入り、カードを待っている状態です |
| 緑 | 打刻を受け付けました |
| 赤 | カードを読み取れませんでした |

緑と赤は**約 1 秒間そのまま点灯してから、待機中の暗い青に戻ります**。1 秒後に青へ戻るのは
正常な動作です。カードの読み取りは一時的に失敗することがあるため、赤が出たらもう一度
かざしてください。

!!! info "打刻音の対応予定"
    音で知らせる仕組みは、音声コーデック（ES8311）を載せた端末での対応として予定して
    いますが、その端末（Atom VoiceS3R）がまだ入荷していないため、現時点では未対応です。

### NFC タイムカード端末

**設置**

1. 乗務員が出入り口で自然に立ち止まれる位置に、カードをかざす面を正面に向けて置きます
2. 台座（PoE ベース）に LAN ケーブルをつなぎます。LAN ケーブルの反対側は、LAN 給電（PoE）に
   対応したスイッチ、または給電用の中継器（PoE インジェクタ）につなぎます。電源はこの
   LAN ケーブル 1 本から供給されるので、電源アダプタは要りません。電源が入ると LED が
   暗い青で点灯します
3. サーバとの通信も同じ LAN ケーブルで行われます。次の「端末の登録」を済ませると打刻できる
   状態になります。LAN 配線が無い拠点では、代わりに Wi-Fi に接続します

!!! info "電源は入れたままにしてください"
    端末は常時起動して打刻を待つ機器です。業務終了時に LAN ケーブルを抜く必要はありません。

!!! info "USB は端末の登録とログの確認にだけ使います"
    USB ケーブルは、端末を PC につないで次の「端末の登録」を行うときと、端末のログを見るとき
    （設置後の確認やトラブル時）にだけ使います。ふだんの電源は USB ではなく LAN ケーブルから
    とります。

!!! warning "カード読み取りユニットは PoE ベースから離して置いてください"
    カードをかざす読み取りユニットは、LAN ケーブルで給電する台座（PoE ベース）の真上や真横に
    置かないでください。台座に近いと読み取りの電波が弱まり、免許証がまったく反応しなくなります。
    ユニットは、つないでいるケーブルの長さのぶんだけ台座から離して置きます。
    置き場所が良いかは、端末を USB で PC につないだときに見られる端末のログで確認できます。
    起動時の `nfc presence` や定期的に出る `nfc heartbeat` の行にある `amp=` の値が 34 付近なら
    問題ありません。20 以下のときは、ユニットの置き場所を変えてください。

**端末の登録**

端末をシステムに登録します。登録は**管理者向けのデバイス登録画面（USB）からすべて行います。
端末に文字を打ち込む操作はありません。**

1. 端末を台座（PoE ベース）に載せて LAN ケーブルをつないだ状態のまま、USB ケーブルも PC に
   つなぎます。登録の最後にサーバとの通信確認があり、LAN がつながっていないと終わりません
2. Chrome または Edge で、管理者から案内されたデバイス登録画面を開きます
3. 「機種」で **NFC タイムカード端末** を選びます
4. 「デバイスラベル」に、どの端末か分かる名前を入力します（例: 設置する営業所の名前）。
   同じラベルで登録し直すと、古い登録は自動で失効します
5. 「セットアップ実行」を押します。登録情報の発行から端末への書き込み、サーバとの通信確認まで
   自動で行われます
6. 画面の「登録済みデバイス」の一覧に、いま登録した端末が「接続中」で表示されれば完了です

!!! info "出荷直後の端末"
    ファームウェアが入っていない端末は、同じ画面の「Web インストーラー」から
    「NFC タイムカード端末」を選んで書き込んでから、上の手順を行ってください。

登録がうまくいかない場合:

- **「セットアップ実行」が「通信確認」で止まって終わらない**: 端末が LAN につながっていません。
  登録情報は端末に書き込み済みなので、台座（PoE ベース）の LAN ケーブルがつながっているかを
  確認してから、一覧のその端末の「再登録」を押してください
- **一覧に出るのに「未接続」のまま**: 同じラベルで 2 回以上登録すると、前の登録は無効になります。
  端末に古い登録情報が残っているとこの状態になるので、LAN をつないだ状態で「再登録」を押して
  ください

**打刻のしかた**

1. LED が暗い青で点灯していること（待機中）を確認します
2. NFC カードを端末のカード面に平らに当て、**緑か赤が出るまでそのまま持っておきます**
3. 緑が点灯したら打刻完了です。カードを離してください
4. 赤が点灯した場合は読み取れていません。当て直してもう一度かざしてください

端末側に打刻履歴の表示はありません。打刻が入ったかどうかは、次の「打刻が入ったかを確認する」で
確認します。

**端末が反応しない場合**

- **LED が消灯している**: 電源が入っていません。台座（PoE ベース）の LAN ケーブルを挿し直し、
  ケーブルの反対側が LAN 給電（PoE）に対応したスイッチや中継器につながっているか確認してください
- **暗い青のまま、緑にも赤にもならない**: カードが読み取り面から離れています。平らに当て直してください
- **赤が続く**: 別のカードでも試して、カード側の問題か端末側の問題かを切り分けてください。
  カードが破損している場合は管理者に連絡してください
- **免許証だけ反応しない（ほかの NFC カードは緑になる）**: 読み取りユニットが PoE ベースに近すぎます。
  ユニットを台座から離して置き直してください（上の「設置」を参照）
- **緑が出るのに管理画面に打刻が出てこない**: 端末がネットワークにつながっていない可能性が
  あります。管理者に連絡してください

### 打刻が入ったかを確認する

打刻が記録されたかどうかは、**管理画面の「タイムカード」タブ**で確認します。

1. 管理画面を開きます
2. 上部のタブから「タイムカード」を選びます
3. 打刻履歴に、該当の乗務員と打刻時刻が並んでいることを確認します

専用機で打刻したものも、アプリの「タイムカード」タブで打刻したものも、ここに同じように
表示されます。

### アプリの「タイムカード」タブで打刻する

専用機を置いていない拠点や、専用機が使えないときは、これまでどおりアプリの「タイムカード」
タブから打刻できます。**この画面は廃止していません。**

1. 「タイムカード」タブをタップします
2. NFC カードをタッチします
3. カードに紐づけられた乗務員名が表示され、打刻が記録されます
4. 当日の打刻一覧が 5 秒間表示されます

!!! info "打刻の送信経路を変更しました"
    アプリからの打刻は、専用機と同じ受け口を通して記録するように変更しました。運行者の
    操作は変わりませんが、打刻に失敗したときは以前より具体的な理由が表示されます。

**カードが読み取れない場合**

- NFC カードを端末の NFC 読み取り位置にしっかりタッチしてください
- 端末の NFC 機能が有効になっているか確認してください
- カードが破損している場合は管理者に連絡してください

## 中間点呼

### 概要

中間点呼は、運行中に電話番号と GPS 位置情報を使って点呼を実施する機能です。

### 電話番号の登録

1. 管理者が提供する QR コードをスキャンして登録ページにアクセスします
2. 電話番号マスタから該当する電話番号を選択します
3. 運転者名と社員コードを入力します
4. 「登録」をタップして登録を完了します

### 点呼の実施

1. 登録済みの電話番号から点呼を実施します
2. GPS 位置情報が自動で取得・送信されます

点呼実施時に端末の GPS 位置情報が自動で記録されます。位置情報の権限を許可してください。

### 登録情報の変更

電話番号や運転者名を変更する場合は、再度 QR コードをスキャンして登録し直してください（同じ電話番号で上書き登録されます）。

## 警告デバイス

### 概要

警告デバイス（Atom VoiceS3R）は、**運行管理者の PC** に USB でつなぐ据置のブザーです。

見張っているのは、運行管理者が乗務員からの呼び出しを受けられる状態かどうかです。トップ画面の
「運行管理者」タブを開いているあいだ、画面は 3 秒ごとに状態をデバイスへ送っています。デバイスは
**この合図が 10 秒以上とだえたら、自分の判断で鳴ります**。画面から「鳴れ」と命令しているわけでは
ないので、タブを閉じた・別のタブに移った・ブラウザが落ちた・PC がフリーズした、のいずれでも
同じように鳴ります。

乗務員が点呼を始めて呼び出しが来たときにも鳴ります。管理者が遠隔点呼に入るか、呼び出しが
なくなると止まります。

### 接続手順

初回だけ、ブラウザにポートの使用を許可させる操作が必要です。

1. 警告デバイスを運行管理者の PC に USB ケーブルでつなぎます
2. トップ画面で「運行管理者」タブを開きます（認証は不要です。認証の画面のままで
   かまいません）
3. 画面上部のバーにある **「警告デバイスを接続」** を押します
4. ブラウザのポート選択ダイアログが出ます。一覧から警告デバイスを選んで「接続」を押します
5. バーの表示が「警告デバイス: 接続」に変わり、左の丸が緑になれば完了です

一度許可すれば、次回からは「運行管理者」タブを開くだけで自動的につながります。

!!! tip "認証ゲートのままで置いてよい"
    見張っているのは「運行管理者」タブがブラウザで開いているかどうかで、認証を通したか
    どうかは関係ありません。普段は認証の画面のままにしておき、必要なときだけ
    認証を通してください。バーはタブに入った時点から出ていて、認証を通したあとも同じ位置に
    残ります。

!!! info "どれを選べばよいか分からないとき"
    ポート選択ダイアログでは、警告デバイスと他の USB 機器が同じ見た目で並ぶことがあり区別が
    つきません。間違えて選んでも壊れません。アプリが自動で見分けて、正しいものにつなぎ直します。

### 鳴ったときの意味

画面上部のバーに理由が表示されます。丸の色は 灰＝未接続 / 緑＝接続 / 赤＝鳴動中 /
黄＝停止済み です。呼び出しが来ているあいだは「着信あり」も出ます。

| 表示 | 意味 | 対処 |
|------|------|------|
| 鳴動中（無音） | 管理者の画面から合図が届かなくなりました。「運行管理者」タブを閉じた、別のタブに移った、ブラウザが落ちた、PC がフリーズした、USB が抜けた | 「運行管理者」タブを開き直してください。画面が固まっている場合はブラウザを再起動します |
| 鳴動中（呼び出し） | 乗務員が点呼を始めて、呼び出しが来ています | 「遠隔点呼」タブから点呼に入ってください。入れば止まります |
| 鳴動中（signaling 未接続） | 呼び出しを受け取る通信が切れています。このままでは乗務員からの呼び出しに気づけません | ネットワークを確認してください。復旧すると自動でつなぎ直します |
| 停止済み（人が止めた・…） | 本体のボタンで音だけ止めた状態です | **異常は続いています。** 上の対処を行ってください |
| 未接続 | 警告デバイスが見つかっていません | USB を挿し直し、上の「接続手順」をやり直してください |

### 本体のボタン

本体のボタンを押すと**音は止まりますが、異常そのものは解消しません**。表示は
「停止済み（人が止めた・…）」に変わり、原因が残っていることを示し続けます。止めているあいだも
5 秒ごとに短く 1 発だけ鳴って、放置されていないことを知らせます。もう一度押すと元に戻り、
原因が残っていればまた鳴り続けます。原因を直すまで放置しないでください。

!!! warning "PC が落ちると鳴りません"
    警告デバイスの電源は USB からとっています。PC の電源が切れる・コンセントが抜けるといった
    場合は、デバイス自身も止まるため鳴りません。停電や PC の電源断は、この仕組みでは
    検知できません。

## デバイス登録

### 概要

Google アカウントを使わずに端末を登録する方法です。管理者が発行した QR コードまたは URL を使って登録します。

### QRコードで登録

1. 管理者が表示する QR コードをカメラでスキャンします
2. 端末のデバイス名と電話番号を入力します
3. 登録が完了すると、自動的にアプリが有効化されます

### URLリンクで登録

1. 管理者から共有された URL（LINE 等）をタップします
2. デバイス登録ページが開きます
3. デバイス名と電話番号を入力し、「登録」をタップします
4. 登録が完了すると、自動的にアプリが有効化されます

### 登録コードで登録

1. 管理者から伝えられた登録コードを入力します
2. デバイス名と電話番号を入力します
3. 管理者の承認を待ちます（QR 永久フローの場合）

### 登録後の確認

登録が完了すると、以降はその端末で自動的にログインされます。
