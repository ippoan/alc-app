# サポート

ALC アプリと点呼に使う機器のサポート体制です。窓口は製作元の**一歩庵**です。

!!! info "連絡先"
    一歩庵の窓口の連絡先（電話番号・メールアドレス）は、導入時にお渡しする連絡先をご覧ください。

---

## 修理体制

事業者は、点呼に使う機器（点呼端末・指静脈の読取装置・体温計・血圧の測定台・電子車検証の読取装置・
アルコール検知器など）の不具合や故障を、一歩庵の窓口へ連絡します。一歩庵は次の手順で対応します。

| 順 | 手順 | 内容 |
|----|------|------|
| 1 | 受付 | 窓口で連絡を受け、事業者名・機器・症状・発生日時を記録します |
| 2 | 遠隔での診断 | 端末の診断ログと故障記録（[故障記録](../admin/equipment-failure.md)）を確認し、原因を調べます |
| 3 | 遠隔での更新 | ソフトウェアやファームウェアの不具合が原因の場合は、修正した版を遠隔で配布して更新します。アプリは自動で新しい版に切り替わります。機器のファームウェアは、版番号を付けた修正版を配布して更新します |
| 4 | 機器の交換 | 遠隔での対応で直らない場合は、機器を交換します |
| 5 | 完了の連絡 | 対応の内容を事業者へ知らせます |

アルコール検知器（タニタ FC-1200）の校正・修理は、メーカーの定める手順に従って行います。

!!! tip "連絡の前に確かめること"
    - 機器の USB ケーブル・電源がつながっているか
    - 点呼端末の画面に表示されている案内の内容（そのまま窓口へ伝えてください）
    - 「故障記録」タブに記録が残っているか

---

## 不具合の受付と改善

不具合は次の 2 つの経路で一歩庵に届きます。

- **故障記録（自動）**: 点呼端末で起きた機器・記録・通信の失敗は、故障記録として自動で集まります
- **事業者からの報告**: 運行管理者が「故障記録」タブから手動で報告するほか、一歩庵の窓口へ連絡します

届いた不具合は、次の流れで改善します。

1. 不具合を改善の課題として記録します
2. 原因を調べ、修正します
3. 修正した版を、下の「品質管理体制」の手順で確かめてから配布します
4. 修正の内容と配布したことを事業者へ知らせます

---

## 品質管理体制

ソフトウェアとファームウェアは、次の手順で品質を確かめてから公開します。

- **自動テスト**: 変更ごとに自動テストを実行し、すべて通らなければ公開されません
- **網羅率の確認**: 点呼の主要な処理は、テストが処理の全体（網羅率 100%）を通っていることを確認します
- **検証環境での確認**: 公開する版を固定し、本番とは別の検証環境で動作を確かめます
- **段階的な公開と切り戻し**: 確かめた版を段階的に公開し、問題があれば前の版へ切り戻せます
- **ファームウェアの版管理**: 機器のファームウェアには版番号を付けて配布し、どの機器にどの版が入っているかを
  確かめられるようにしています

このマニュアルも Web で公開しており、更新のたびに自動で作り直されます。印刷用のページから PDF にもできます
（[ダウンロード](../downloads.md)）。
